# inq_hpold — прив'язка до рядків панелей (native renderer)

Це **робоча гілка розробки**, не реліз.

## Чому змінюється рендерер

Повноекранний Gameface-оверлей не має безпосереднього доступу до Flash display-list штатної панелі WoT 2.4.1. Статичні координати не можуть гарантовано повторювати перемикання режимів панелі, масштаб UI і перестановку рядків.

Новий рендерер використовує реальні `playersPanel.listLeft/listRight` та `getHolderByVehicleID`, додає HealthRow всередину правильного item і прив'язує його до vehicleIcon / vehicleTF. Приховує індикатор, якщо рядок невидимий.

## Реалізація
- `as3/src_flash/src/inq/hpold/battle/HpPanel.as` — прив'язка рядків і HP.
- `as3/src_flash/src/inq/hpold/battle/HealthRow.as` — візуальні сегменти й текст.
- `as3/src_flash/src/inq/hpold/injector/` — самостійна ін'єкція панелі.
- `python/gui/mods/inq_hpold_native/` — Python 2.7 provider, події арени, налаштування, життєвий цикл.
- `python/gui/mods/mod_inq_hpold.py` — точка входу.
- `build_native.py` — складання окремого WOTMOD; навмисно не випускає файл без скомпільованого `as3/bin/inq_hpold.swf`.

## До релізу
1. Зібрати SWF із наявних ActionScript джерел та потрібних WoT SWC SDK.
2. Перевірити linkage, назви компонентів і імпорти в клієнті 2.4.1.
3. Запустити у бою / реплеї без паралельно встановленого старого HP-мода та перевірити `game.log`.
4. Лише після цього замінювати RC2 в основній гілці.

У цьому варіанті Gameface не використовується для самого прикріплення HP до рядків. Це свідомий вибір заради точного збігу зі штатними панелями. SWF включатиметься *всередину власного* `inq_hpold.wotmod`, без окремого Python-ядра.
