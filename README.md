# inq_hpold

Самостійний HP-індикатор для командних панелей WoT 2.4.1.

- `python/gui/mods/` — Python 2.7: HP, бойові події й передача даних.
- `as3/src_flash/src/` — AS3: прив’язка HP до рядка танка та відображення оригінальних PNG-шкал через bitmap-маску без розтягування.
- `as3/libs/` — дев’ять SWC-бібліотек для компіляції.
- `hpbars/` — чотири оригінальні PNG.
- `build.py` — збірка ZIP_STORED WOTMOD.
- `.github/workflows/release.yml` — автоматична збірка.

Колір шкали противника автоматично повторює налаштування клієнта: червоний у звичайному режимі та фіолетовий у режимі дальтонізму.

Не використовуються Gameface, додаткове ядро або функції фарбування іконок танків. Чотири PNG з `vendor/res/gui/hpbars/` пакуються в WOTMOD разом зі SWF.

**Для тестування**: GitHub Actions → Build and Release → Artifacts або GitHub Releases (коли релізний workflow успішно завершено). Видаляйте старі версії `inq_hpold` перед запуском.

Роботу в реальному бою ще необхідно перевіряти за скріншотом і `game.log`.

**Керування:** Alt — тимчасовий показ HP; Ctrl+Alt — перемикання постійного показу. Реєстрації в ModsSettingsAPI немає, HP-шкали завжди ввімкнені.

**Відновлення HP:** обробники HP дозволяють і зменшення, і збільшення здоров'я (для «Натиску»). У самому режимі функціональність ще не перевірено.
