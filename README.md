# inq_hpold

Самостійний HP-індикатор для командних панелей WoT 2.4.1.

- `python/gui/mods/` — Python 2.7: HP, бойові події й передача даних.
- `as3/src_flash/src/` — AS3: прив’язка HP до рядка танка та відображення оригінальних PNG-шкал через Scaleform TextField з PNG-зображеннями.
- `as3/libs/` — дев’ять SWC-бібліотек для компіляції.
- `hpbars/` — чотири оригінальні PNG.
- `build.py` — збірка ZIP_STORED WOTMOD.
- `.github/workflows/release.yml` — автоматична збірка.

Колір шкали противника автоматично повторює налаштування клієнта: червоний у звичайному режимі та фіолетовий у режимі дальтонізму.

Не використовуються Gameface, додаткове ядро або функції фарбування іконок танків. Чотири PNG з `vendor/res/gui/hpbars/` пакуються окремо в WOTMOD, а SWF посилається на них через `img://gui/hpbars/...`.

**Для тестування**: GitHub Actions → Build and Release → Artifacts або GitHub Releases (коли релізний workflow успішно завершено). Видаляйте старі версії `inq_hpold` перед запуском.

Роботу в реальному бою ще необхідно перевіряти за скріншотом і `game.log`.

## Налаштування й клавіші

- У меню модифікацій (якщо доступний `gui.modsSettingsApi`) є запис `inq_hpold` з прапорцем **Показувати HP-шкали**. Він вмикає/вимикає PNG-шкали, але не числовий текст HP.
- Утримуйте **Alt**, щоб бачити HP; **Ctrl+Alt** перемикає постійний показ.
- Мод працює без ModsSettingsAPI; в такому разі налаштування шкал за замовчуванням увімкнене.

## Оптимізація та відновлення здоров'я

- При незмінних HP/кольорі/видимості шкали `TextField.htmlText` не перепарсується; позиціонування виконується окремо для видимих рядків.
- Джерела HP (`PlayersPanel.updateVehicleHealth` і `arena.onVehicleHealthChanged`) приймають і зменшення, і збільшення здоров'я, включно з лікуванням у спеціальних режимах.
- Бойова перевірка лікування в режимі «Натиск» ще не проведена; також необхідно перевірити актуальність колбеків і взаємодію з іншими модами в реальному клієнті.
