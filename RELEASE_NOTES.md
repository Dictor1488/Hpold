# inq_hpold 0.1.0 RC1

Тестова збірка HP-індикаторів для панелей команд WoT 2.4.1.

**Статус:** Release Candidate. Відображення та сумісність з ігровим клієнтом ще не перевірено в реальному бою.

### Вміст
- HP союзників і противників: текст, заповнення шкали, колір для дальтонізму
- Gameface HTML/CSS/JS + Python
- Перемикання режиму Ctrl + X (із конфігурацією), тимчасовий показ через Alt
- Окремий `.wotmod`, без SWF

### Встановлення
Завантажити файл `inq_hpold_0.1.0-rc1.wotmod` нижче в розділі Assets та помістити його в `World_of_Tanks/mods/2.4.1.0/`. Видалити попередній варіант цього мода перед встановленням.

### Тестування
Перевірити відображення в бою, режими панелей, Ctrl+X, Alt, загибель техніки та перехід між боями. Якщо є помилки — додати `game.log` і скріншот.

SHA-256 файлу доступний у `SHA256SUMS.txt`.
